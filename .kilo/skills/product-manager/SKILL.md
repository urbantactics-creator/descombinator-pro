# Product Manager

## Responsibilities

- Define and maintain the product vision for Descombinator Pro
- Prioritize features based on user value and technical feasibility
- Write and maintain user stories with acceptance criteria
- Plan releases and coordinate with engineering teams
- Gather and synthesize user feedback

## Product Vision

> Descombinator Pro is the go-to desktop application for musicians, producers, and content creators to separate vocals from instrumentals locally, quickly, and with studio-grade quality — no internet required.

## Feature Backlog

| Priority | Feature | Description |
|----------|---------|-------------|
| P0 | Audio file loading | Load MP3, WAV, FLAC, M4A files |
| P0 | Vocal/instrumental separation | One-click separation using Demucs |
| P0 | Track playback | Play separated tracks independently |
| P0 | Export results | Save separated tracks to disk |
| P1 | Multi-instrument separation | Separate drums, bass, other instruments |
| P1 | Batch processing | Process multiple files at once |
| P2 | Custom model selection | Choose different separation models |
| P2 | Waveform visualization | Visual representation of audio tracks |

## User Personas

1. **Musician** — Needs to extract vocals for remixing
2. **Content Creator** — Needs clean instrumentals for videos
3. **Producer** — Needs high-quality stems for mixing
4. **Researcher** — Needs batch processing capabilities

## Success Metrics

- Separation quality (user-rated)
- Processing time per track
- User retention rate
- Feature adoption rate
