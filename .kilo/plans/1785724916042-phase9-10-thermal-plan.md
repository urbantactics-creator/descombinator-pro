## Part B — Thermal Monitoring

### B1. New Module: `engine/performance/thermal.py`

**Skills**: `performance-engineer`, `python-backend-engineer`, `cross-platform-engineer`

```
Classes:
  ThermalState(StrEnum)     — NORMAL / WARM / HOT / CRITICAL
  ThermalSnapshot(BaseModel) — cpu_temp_c, gpu_temp_c, state
  ThermalMonitor            — async sample(), check_thresholds(), apply_throttle()
```

**Cross-platform sensors**:

| Sensor | Linux | macOS | Windows |
|--------|-------|-------|---------|
| CPU temp | `psutil.sensors_temperatures()` → `coretemp`/`k10temp` | `{}` → `None` | `{}` → `None` |
| GPU temp | `nvidia-smi` subprocess | `None` | `nvidia-smi` subprocess |

**Thresholds**:

| State | CPU | GPU | Action |
|-------|-----|-----|--------|
| NORMAL | < 70°C | < 80°C | None |
| WARM | 70–80°C | 80–85°C | Log warning |
| HOT | 80–90°C | 85–95°C | Reduce threads, yield between segments |
| CRITICAL | > 90°C | > 95°C | Pause separation, emit emergency signal |

### B2. Extend `ResourceSnapshot`

In `engine/performance/monitor.py`, add to `ResourceSnapshot`:

```python
cpu_temp_c: float | None = None
gpu_temp_c: float | None = None
```

### B3. Throttling Integration Points

| File | Change |
|------|--------|
| `engine/demucs/separator.py` | Add `PAUSED` to `SeparationState`. Between pipeline segments, `await asyncio.sleep()` when HOT. On CRITICAL, set state PAUSED and return partial result. |
| `app/services/separation_service.py` | Accept `ThermalMonitor | None` in constructor. Call `monitor.sample()` in the `try` block of `separate()` and `separate_loaded()`. If CRITICAL, raise `ThermalError`. |
| `app/controllers/main_controller.py` | Add `thermal_warning = Signal(str, float)`. Create `ThermalMonitor` in `__init__`, pass to `SeparationService`. Connect thermal callback to signal. |
| `app/ui/main_window.py` | Display `cpu_temp_c`/`gpu_temp_c` in `_status_bar` when not None. Show warning overlay when HOT/CRITICAL. |

**Thread safety**: `SeparationWorker` runs in `QThreadPool` with its own event loop. `ThermalMonitor.sample()` is async but called from `SeparationService.separate()` which runs in that thread's loop. No cross-thread issues — the monitor is thread-local.

def get_resource_path(relative: str) -> Path:
    if getattr(sys, 'frozen', False):
        base = Path(sys._MEIPASS)
    else:
        base = Path(__file__).parent
    return base / relative

### C4. GitHub Actions Build Workflow

**New file**: `.github/workflows/build.yml`

```yaml
name: Build
on:
  push:
    tags: ['v*']
  workflow_dispatch:

jobs:
  build:
    runs-on: ${{ matrix.os }}
    strategy:
      matrix:
        os: [ubuntu-latest, windows-latest, macos-latest]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-python@v5
        with: { python-version: '3.12' }
      - run: pip install -e ".[dev]"
      - run: pyinstaller descombinator.spec
      - uses: actions/upload-artifact@v4
        with:
          name: descombinator-${{ matrix.os }}
          path: dist/

  release:
    needs: build
    if: startsWith(github.ref, 'refs/tags/v')
    runs-on: ubuntu-latest
    permissions: { contents: write }
    steps:
      - uses: actions/download-artifact@v4
      - uses: softprops/action-gh-release@v2
        with: { files: '**/*' }
```
