# Icons Directory

Place application icons in this directory:
- SVG or PNG format recommended
- Common sizes: 16x16, 24x24, 32x32, 48x48, 64x64, 128x128, 256x256
- Icons referenced in QSS files should be available via Qt resource system or file paths

For now, this directory is a placeholder. In a production build, you would:
1. Add actual icon files (.svg, .png)
2. Create a Qt resource file (.qrc)
3. Reference icons in QSS using qrc:/// or relative paths
